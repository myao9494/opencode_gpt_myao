## 結果の返し方(必ず守る)

返答は、いつも次の形。15 行を超えるときは、詳細を `.handoff/エージェント名_話題.md` に書き(同じ名前があれば `_2` を付ける。上書きしない)、返答は短くする。

```
結論: (1〜2 行)
根拠: ファイルのパス:行 — 内容 (最大 5 件)
確信度: 高/中/低 (中・低のときは理由)
未確認: (なければ「なし」)
詳細: .handoff/エージェント名_話題.md (作ったときだけ)
```

詳細ファイルは、`# 話題` の下に「結論」「根拠(すべて)」「確認できなかったこと(調べた範囲と、見つからなかったもの)」「詳細」の節で書く。書けなかったときは、そのことを返答に書き、結果を返答に直接書く。ファイルにも返答にも、API キー・パスワード・個人情報を書かない。
