## 前提

- 実行: `<スキルのフォルダ>\run.bat`(Mac・Linux は `run.sh`。引数は同じ)。スキルのフォルダは、読み込んだときに示される。`.venv` が無いと出たら、止めて報告する。
- 探せる・読めるのは、設定(`config.local.json`)の `roots` のフォルダだけ。外は拒否される。回避しない。
- **読み取り専用。**
- Mac では `content` と `read` だけが動く(`names` の Everything は Windows 専用)。

## 守ること

- **探したら、続けて読む。** 読んでよいかを聞き返さない。多くの資料を読み比べる調査は、`researcher` に任せる。
- 見つからなければ、そう答え、試した語と方式を書く。ありそうなパスを推測で答えない。

## 探す

| 探すもの | コマンド |
|---|---|
| ファイルの**中身** | `content`(まずこれ) |
| ファイルやフォルダの**名前** | `names`(Windows) |

```
run.bat content 見積 金額
run.bat content "契約書 -ドラフト" --ext docx,pdf --limit 10
run.bat content 会議 --folder C:/Docs/案件A --mode hybrid
run.bat names "議事録 2026" --kind file --ext md,docx
```

- 語はスペースで AND、`OR` で OR、`-語` で除外(`-語` を含むときは、全体を `"` で囲む)。
- `--mode`: `keyword`(既定)。見つからなければ `hybrid`(意味の近いものも拾う)。
- `--ext` で拡張子、`--folder` で場所を絞る。`names` の `--kind` は `file`・`folder`。
- 結果が長いときは `--out .handoff/finder_見積.md`(画面には件数とパスだけ)。
- 0 件なら、語を変える・短くする、`--mode hybrid`、`targets`(インデックス済みのフォルダの一覧)を見る。

## 読む

```
run.bat read C:/Docs/案件A/議事録.md
run.bat read C:/Docs/案件A/議事録.md --from-line 120
```

- 検索結果のパスをそのまま渡す(5 個までまとめて)。行番号つきで出る。根拠は「パス:行」で書く。
- **作業フォルダの外のファイルは、これで読む**(`read` の道具では、許可の確認で止まる)。
- 1 ファイル 12,000 文字まで。続きは、最後の行に出るコマンドで読む。
- テキスト(`.md` `.txt` `.csv` など)だけ。Word・Excel・PowerPoint・PDF は、スキル `doc-convert` で変換してから読む。

## 結果の読み方

- 返答には、関係の高いパス(最大 5 件)と、分かったことを書く。残りの件数も書く。
- 「一致: 意味だけ」は、**検索語を含まない**。関係の無いものが混ざりやすいので、抜粋で確かめてから使う。
- 「AI のまとめ (未レビュー)」は根拠にしない(原典を探す手がかりだけ)。「(レビュー済)」と `99_knowledge/` は根拠にしてよい。
- 「対象外・除外・重複の N 件は除きました」は、設定の外か除外のものがあったという意味。

## うまくいかないとき

| 症状 | 対処 |
|---|---|
| 「設定ファイルがありません」「roots が空です」 | 止めて報告する(`config.sample.json` から `config.local.json` を作る必要がある) |
| 「サーバーに接続できません」 | Local-fulltext-search・Everything が起動しているか、確かめてもらう(`run.bat check`) |
| 「環境変数 … にパスワードを設定してください」 | 報告する |
| 「roots の外です」 | 探せないし読めない。報告する |

できなかったことは、そのまま報告する。別の方法で回避しない。
